# Stage 5 evaluation protocol

Declared before formal test scoring. Machine-readable plan: config/stage5_evaluation.json. The frozen raw LR remains selected, threshold0.5, with the original eight inputs, label and split. Frozen Dummy and raw RF are prespecified descriptive comparators. No fitting, calibration, selection or tuning is permitted.

Before scoring: verify hashes, split uniqueness/disjointness, selected-field schema, stored training-only imputer modes and encoder categories, model parameters, and original training/preprocessing source hashes. Seal the evaluation source and plan hashes in pretest_checkpoint.json before accessing test labels for scoring.

Primary metrics are unweighted. Ordinary respondent-level bootstrap uses2000 paired draws, seed20261104 and percentile95% intervals. Undefined metrics are omitted per metric with valid/invalid counts; intervals need at least90% finite replicates. Recall needs positives, FPR needs negatives, precision needs predicted positives, AUC needs both classes and AP needs positives. F1 is undefined only when its denominator is zero. Paired differences share identical draws. These intervals condition on the fitted objects and empirical test distribution; they omit training, selection, transportability and complex-survey uncertainty. Weighted points use finalwt separately without design confidence intervals.

LR calibration uses10 equal-width bins on[0,1], with the last bin including1. Save all bin counts, empty bins and Wilson95% intervals for observed fractions; bins with n<30 are flagged. Plot the prediction distribution with the same boundaries. Brier and binned error are diagnostics, not calibration certification. No corrective calibration follows.

Validation permutation importance shuffles each original input column30 times, seed20261105, scoring AP through the entire frozen LR Pipeline. Save AP drops and their mean/SD; SD is permutation variation, not an inferential interval. Importance is global, model-specific, noncausal and affected by correlated inputs/unrealistic shuffled combinations.

Codebook PDF78 maps agecat1..8 to18-24,25-34,35-44,45-54,55-61,62-69,70-74,75+. Primary age groups are18-34,35-61,62+, with the full age bands retained as prespecified secondary detail. Codebook PDF79 defines annual household USD income bands; combine1/2 as under30000,3..6 as30000-74999 and7..9 as75000+. These represent resources and the older-adult oversample; they do not assert natural fairness thresholds. All three models receive the same subgroup definitions. Save n, positive/negative counts, recall, FPR and other defined metrics. Flag n<100 or either class<30; report empty/one-class groups and unknown codes. Do not tune group thresholds or claim absence of bias from similar scores.

Reuse stage-four stability evidence; no new model fits. Save ID-level test predictions, metrics, curves, bootstrap draws, reliability bins, subgroup results, source/config hashes and completion status in a new output directory. Preserve earlier records. Plotting may read saved results without rescoring. Reproducing the frozen evaluation is allowed for verification, never for selection.
